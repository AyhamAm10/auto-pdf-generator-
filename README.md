# نظام أتمتة توليد محاضرات وملخصات PDF (الإصدار الثاني v2)
### مركز تصوير كلية التربية - وحدة الخدمات الجامعية

نظام متكامل ومبني على **TypeScript** و **Node.js** و **Puppeteer** لتحويل ملفات الـ JSON إلى ملفات **PDF** أكاديمية فائقة الجمال والتنسيق بتصميم عصري راقٍ، متطابقة مع الهوية البصرية لمركز تصوير كلية التربية.

---

## 🚀 طريقة التشغيل

المشروع الأساسي المعتمد هو مجلد `v2/`:

### 1. تشغيل مباشر عبر ملف Batch (Windows):
- انقر نقراً مزدوجاً على `v2/generate.bat` (أو `generate.bat` في المجلد الرئيسي).

### 2. سطر الأوامر (Command Line):
```bash
cd v2

# توليد PDF من data.json الافتراضي
npm run generate

# أو وضع التطوير
npm run dev
```

```text

    ├── application/           # إدارة التوليد والتوافق
    ├── domain/                # تعريف المستند والكيانات
    ├── infrastructure/        # محرك Puppeteer ومحمّل الأصول
    ├── renderer/              # قوالب التنسيق والـ CSS والكتل
    └── themes/                # ثيمات الأقسام (الإرشاد، معلم صف، المناهج، رياض الأطفال)
```

## 🎨 التحسينات البصرية الحديثة المطبقة في v2:
1. **خطوط عربية حديثة**: اعتماد خطوط `IBM Plex Sans Arabic` و `Readex Pro` فائقة الوضوح.
2. **بطاقات مفاهيم مودرن**: بطاقات ذات حواف ناعمة وخلفية خفيفة (`#FAFBFD`) وظلال خفيفة، مع استبدال الحواف العريضة القديمة.
3. **وسم "مثال تطبيقي"**: تصميم شارة مستديرة (Pill Badge) حديثة وواضحة بلون زمردي هادئ.
4. **صناديق تنبيه وتذكير متناسقة**: ألوان باستيل ناعمة للملاحظات، الأسئلة الامتحانية، والتنبيهات الأكاديمية.
5. **ترويسة وفوتر متناسقان**: ترويسة أكاديمية واضحة في الصفحة الأولى، وفوتر بهوامش موحدة (12mm) ورقم صفحة بارز بدقة.

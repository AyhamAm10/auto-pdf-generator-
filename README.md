# نظام أتمتة توليد محاضرات وملخصات PDF (الإصدار الثاني v2)
### مركز تصوير كلية التربية - وحدة الخدمات الجامعية

نظام متكامل ومبني على **TypeScript** و **Node.js** و **Puppeteer** لتحويل ملفات الـ JSON إلى ملفات **PDF** أكاديمية فائقة الجمال والتنسيق بتصميم عصري راقٍ، متطابقة مع الهوية البصرية لمركز تصوير كلية التربية.

---

## 🚀 طريقة التشغيل

المشروع الأساسي المعتمد هو مجلد `v2/`:

### 1. تشغيل مباشر عبر ملف Batch (Windows):
- انقر نقراً مزدوجاً على `v2/generate.bat` (أو `generate.bat` في المجلد الرئيسي).

### 2. سطر الأوامر (Command Line):
```bash
cd v2

# توليد PDF من data.json الافتراضي
npm run generate

# أو وضع التطوير
npm run dev
```

## 🎨 التحسينات البصرية وقواعد التنسيق المعتمدة:
1. **خطوط عربية حديثة**: اعتماد خطوط واضحة ومقروءة للطباعة بتباعد أسطر `1.5` ثابت.
2. **توزيع ثيمات الأقسام والهوية البصرية الرسمية**:
   - **الإرشاد النفسي**: كحلي أزرق ملكي / بترولي (`#005BB5`) مع مفاتيح وعناوين فرعية بلون بوردو (`#881337`) وشعار أزرق (`logo.png`).
   - **المناهج وتقنيات التعليم**: بوردو عنابي داكن (`#881337`) مع مفاتيح وعناوين فرعية بلون كحلي أزرق (`#005BB5`) وشعار بوردو (`photo_2026-09-09_13-47-31.png`).
   - **معلم صف**: أخضر زمردي عميق (`#064E3B`) مع مفاتيح وعناوين فرعية بلون بوردو متباين (`#881337`) وشعار أخضر (`photo_2026-09-09_13-47-29 (2).png`).
   - **رياض الأطفال / التربية الخاصة**: بنفسجي ملكي (`#4C1D95`) مع مفاتيح وعناوين فرعية بلون بترولي متباين (`#0E7490`) وشعار بنفسجي (`photo_2026-09-09_13-47-29.png`).
3. **قاعدة التباين المتبادل (Mutual Contrast)**:
   - منع استخدام تدرجات مشتقة من لون العنوان الرئيسي للعناوين الفرعية والمفاتيح داخل الفقرات؛ بل استخدام لون متباين قوي لإبراز النقاط ورؤوس الفقرات.
4. **قواعد الصياغة والمحددات وكروت التنبيه**:
   - **الأقواس `(...)`**: النصوص والملاحظات بين قوسين تبقى كما هي ضمن سياق الفقرة (`p`) دون تحويلها لكروت.
   - **علامات التنصيص `"..."`**: تُلوّن تلقائياً باللون الثانوي (`secondary`) لإبرازها.
   - **المحددات `$$...$$`**: مخصصة لكلام الدكتور والتنبيهات وتوضع في كرت بعنوان **`مهم`**.
   - **المحددات `~...~`**: مخصصة للفقرات الإثرائية وتوضع في كرت بعنوان **`للاطلاع`**.
   - **صيغ الأسئلة والأجوبة**: تبدأ بـ `س:` للسؤال و `ج:` للجواب وتُبرز بخط عريض ملون تلقائياً.
   - **ترشيد الكروت**: الأولوية دائماً لتدفق الفقرات العادية، والكروت تحافظ على تصميم بيزك ناعم مع شفافية خفيفة.
5. **الالتزام الحرفي التام**: الالتزام بنص ومعلومات المحاضرة الأصلية حرفياً دون أي إضافات خارجية.
6. **ترويسة وفوتر متناسقان**: ترويسة أكاديمية واضحة في الصفحة الأولى، وفوتر بهوامش موحدة (12mm) ورقم صفحة ديناميكي دقيق.
